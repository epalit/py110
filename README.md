# Python Programming (PY110) - 2026

This repository contains exercises and notes from working through Launch School’s **Programming Foundations with Python: Intermediate**.

It continues directly from PY101 and focuses on developing a deeper understanding of Python's built-in collection types and the techniques used to work with them effectively.

The goal at this stage is to become confident selecting appropriate data structures, transforming data efficiently, and writing clear, idiomatic Python code.

## Focus Areas

- Strings, lists, tuples, sets, frozensets, and dictionaries
- Problem solving using PEDAC-style thinking

## Structure

- Separate directory for each lesson
- Lesson notes in `.md` files inside the `notes` directory for each lesson

## Running Code

Run any file with:

```bash
python filename.py
```
